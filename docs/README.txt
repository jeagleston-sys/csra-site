==================================================================
 HOW TO ADD YOUR SAMPLE REPORT PDF
 CSRA Precision Imaging website
==================================================================

The homepage "Download Sample Report (PDF)" button links to:

    docs/sample-roof-report.pdf

That file does not exist yet — the button will 404 until you add it.

STEPS:
  1. Put together a real (or sanitized/example) roof moisture
     assessment report as a PDF — this can be a past deliverable
     with client-identifying details removed, or a mock example.
  2. Name it exactly:  sample-roof-report.pdf
  3. Place it in this folder (docs/) at the repo root.
  4. Commit and push via GitHub Desktop as usual — no code changes
     needed, the button already points here.

Keep the file reasonably small (a few MB) so it loads quickly.
